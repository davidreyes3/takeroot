## People

- יֶלֶד = boy, child ; gender: m ; root: י-ל-ד ; ex: הילד קורא ספר | The boy is reading a book
- יַלְדָּה = girl ; gender: f ; root: י-ל-ד
- אִישׁ = man ; gender: m ; note: plural is אֲנָשִׁים, which is irregular
- אִשָּׁה = woman ; gender: f ; note: plural is נָשִׁים, which is irregular
- מוֹרֶה = teacher (m) ; gender: m ; root: י-ר-ה
- מוֹרָה = teacher (f) ; gender: f ; root: י-ר-ה ; key: f
- חָבֵר = friend ; gender: m ; root: ח-ב-ר

## Around the house

- בַּיִת = house, home ; gender: m ; root: ב-י-ת ; ex: הבית גדול | The house is big
- דֶּלֶת = door ; gender: f ; root: ד-ל-ת
- חַלּוֹן = window ; gender: m ; root: ח-ל-נ
- שֻׁלְחָן = table ; gender: m ; root: ש-ל-ח
- כִּסֵּא = chair ; gender: m ; root: כ-ס-א
- סֵפֶר = book ; gender: m ; root: ס-פ-ר

## Food and drink

- מַיִם = water ; gender: m ; number: pl ; note: always plural in Hebrew
- לֶחֶם = bread ; gender: m ; root: ל-ח-מ
- חָלָב = milk ; gender: m ; root: ח-ל-ב
- קָפֶה = coffee ; gender: m
- תַּפּוּחַ = apple ; gender: m

## Animals

- כֶּלֶב = dog ; gender: m ; root: כ-ל-ב ; ex: הכלב קטן | The dog is small
- חָתוּל = cat ; gender: m ; root: ח-ת-ל
- סוּס = horse ; gender: m ; root: ס-ו-ס
- צִפּוֹר = bird ; gender: f ; root: צ-פ-ר

## Time and place

- יוֹם = day ; gender: m ; root: י-ו-מ
- לַיְלָה = night ; gender: m ; root: ל-י-ל
- שָׁנָה = year ; gender: f ; root: ש-נ-ה
- עִיר = city ; gender: f ; note: feminine despite the masculine-looking ending
- רְחוֹב = street ; gender: m ; root: ר-ח-ב
