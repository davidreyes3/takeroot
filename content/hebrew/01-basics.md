## Greetings

- שָׁלוֹם = hello, goodbye, peace ; root: ש-ל-מ ; note: greeting and farewell both
- בֹּקֶר טוֹב = good morning
- עֶרֶב טוֹב = good evening
- לַיְלָה טוֹב = good night
- לְהִתְרָאוֹת = see you later ; root: ר-א-ה
- מָה שְׁלוֹמְךָ = how are you (to a man)
- מָה שְׁלוֹמֵךְ = how are you (to a woman) ; key: f

## Please and thank you

- תּוֹדָה = thank you ; root: י-ד-ה
- תּוֹדָה רַבָּה = thank you very much
- בְּבַקָּשָׁה = please, you're welcome ; root: ב-ק-ש
- סְלִיחָה = sorry, excuse me ; root: ס-ל-ח

## Yes and no

- כֵּן = yes ; pos: particle
- לֹא = no, not ; pos: particle
- אוּלַי = maybe ; pos: adv
- בְּסֵדֶר = okay, fine

## Small words

- גַּם = also, too ; pos: particle
- אֲבָל = but ; pos: particle
- אוֹ = or ; pos: particle
- עִם = with ; pos: prep
- בְּלִי = without ; pos: prep

## Pronouns

- אֲנִי = I ; pos: pron
- אַתָּה = you (m.sg) ; pos: pron
- אַתְּ = you (f.sg) ; pos: pron
- הוּא = he, it ; pos: pron
- הִיא = she, it ; pos: pron
- אֲנַחְנוּ = we ; pos: pron
- הֵם = they (m) ; pos: pron
- הֵן = they (f) ; pos: pron
